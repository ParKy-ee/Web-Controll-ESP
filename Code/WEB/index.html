คู่มือการติดตั้งและ Train โมเดลด้วย Python CLI

ทำตาม 3 ขั้นตอนดังนี้เพื่อสร้าง AI ตรวจจับท่าทางจากไฟล์ CSV ที่บันทึก:

1. ติดตั้ง Library สำหรับ Machine Learning:
pip install -r requirements-ml.txt
2. สั่ง Train โมเดลด้วยข้อมูล CSV (Random Forest / SVM Classifier):
python tools/train_model.py whist/*.csv --window 1.0 --output models/pose_model
3. เปิด Local Inference API Server เพื่อตรวจจับสดหรือ Replay:
python tools/serve_model.py --model models/pose_model/model_bundle.joblib --port 8765

💡 โครงสร้างชุดข้อมูลและโมเดลอิงตามสถาปัตยกรรม Arduino Ble 33 / PlanKO โดยดึงคุณลักษณะ (Features) ความถี่ 20Hz ครอบคลุม Mean, Std, RMS, Range, Slope, Vector Magnitude และ Mount-Site Isolation เพื่อให้โมเดลแยกแยะท่าทางได้อย่างแม่นยำ
